# 配置中心手机授权

配置中心来自订阅 Spider，并非 FBox 自带的账号系统。手机适配识别配置 Spider 的扫码/注册操作卡片，保留原始 action，不影响清除、账号、短信、播放及其他设置。界面不再显示原插件的扫码弹窗。

## 支持范围

当前适配 `csp_PanConfigGuard` / `csp_PanConfig` 的 `do=pan` 本地接口。当前订阅已实际核对的登录会话包括夸克、UC Cookie、UC TV Token、百度网盘、115、天翼、哔哩哔哩、光鸭。迅雷和移动的短信登录、123 的账号登录沿用插件现有入口。

登录会话首先用原始 HTTPS 授权链接尝试打开对应 App，仅当 Android 能解析到对应包时启动。没有通用的“任意 App 授权”协议；特定版本可能不接受扫码链接，官方 OAuth SDK 需要注册应用，且 OAuth Token 不一定能替代插件使用的 Cookie。不会将打开 App 首页当作授权成功，也不会伪造官方客户端参数。

不支持 App 直达时可以在浏览器继续同一授权会话。百度、115、天翼、哔哩提供官方网页登录页，用户完成登录并主动点击保存后，才把对应域名的 Cookie 交给当前订阅。网页本身的账号、验证码和风控能力由服务方决定，不能保证所有版本均可完成登录。夸克和 UC 的手机主页会跳往下载宣传页，因此不将它们包装成网页登录入口，保留同会话浏览器授权或手动 Cookie。UC TV Token 和光鸭 Token 不会用 Cookie 冒充，可继续浏览器授权或手动粘贴 Token。

`csp_Config` 的旧版扫码操作及无法识别的平台会提示接口不兼容，保留原有手动/账号入口，不调用旧的扫码弹窗。任意其他 Spider 不按名称猜测拦截。扩展新插件必须先核对它的会话及凭据存储协议。

## 会话契约

请求仅发到 FBox 的 `127.0.0.1` 服务 `/proxy`，携带 `do=pan`、明确的 `siteKey` 和以下字段。网络层禁用代理、重定向，设置超时及响应大小限制；不记录 URL、会话或凭据。

| action | 输入 | 成功语义 |
| --- | --- | --- |
| loginStart | provider | code=0，非空 taskId、qrUrl；只是创建会话 |
| loginPoll | provider、taskId | status=success 才表示插件已保存凭据；terminal 表示结束 |
| loginCancel | provider、taskId | 尽力取消指定会话 |
| set…Cookie / set…Token | value | code=0 表示插件接受保存；不额外声称第三方已验证有效 |
| status | 无 | 读取状态或注册入口，不读取 credentials |

每次启动只拥有一个会话，1.5 秒串行轮询，5 分钟超时；连续三次网络失败停止。重试、关闭面板、页面销毁都会取消会话。启动中的迟到响应也会取消，不会重新拉起 App。切换订阅后拒绝向旧来源写入。配置持久化沿用插件，不建立第二套登录文件。

嵌入式二维码图片仅用于提取链接，不展示二维码。只允许该平台官方域名的 HTTPS 链接，拒绝 file/content/javascript/intent URL、用户信息、非标准端口及伪装域名。网页没有 JavaScript 原生桥，禁止文件访问、混合内容和跨平台主页面跳转。网页保存操作只读取对应平台 Cookie，不自动读取或发送其他账号的凭据。

## 验证

`ConfigAuthProviderTest` 检查来源边界、平台区分、Cookie 检测和恶意链接。`AuthSessionTest` 在专用模拟器使用假后端检查等待/成功、迟到取消、回调抑制、过期/网络失败、错误响应，以及图片二维码解析和 Intent 清理。测试不会向真实账号发送验证码或确认授权。

`AuthUiTest` 验证未安装 App 的提示、可用的替代入口、关闭时取消，以及空输入不能保存、保存被插件接受后才刷新。2026-11-10：5 项 JVM 测试、9 项授权仪器测试、27 项现有页面回归分批通过；搜索返回用例修复了动画未结束时立即断言销毁状态的时序问题。76 组布局契约检查通过，签名 Release 构建通过。完整 `lintRelease` 仍有 6 项既有错误（旧 AppCompat 检查器与 AGP 不兼容，以及 HomeActivity、旧布局、弹幕 DiffUtil 和电视清单规则），未作为本次授权功能改动一并修复。

实际账号的最终授权需要用户在服务方页面确认。已安装的百度网盘不处理当前订阅返回的 HTTPS 扫码会话链接，必须使用可用的网页或手动入口，不能宣称已完成百度 App OAuth 接入。
